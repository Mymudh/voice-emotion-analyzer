# 🎤 AI Voice Emotion Analyzer

An AI-powered application that analyzes human voice recordings
and predicts emotional states using machine learning.

## Features
- Voice recording
- Audio upload
- Emotion detection
- Confidence score
- Emotion probability chart
- Audio visualization
- Voice feature extraction
- Emotion history

## Technologies
- Python
- Streamlit
- Machine Learning
- Deep Learning
- Librosa
- Speech Processing
- Scikit-learn
- Plotly

## Architecture

User Voice
     ↓
Audio Preprocessing
     ↓
Feature Extraction
     ↓
ML / Deep Learning Model
     ↓
Emotion Classification
     ↓
Visualization & Results
